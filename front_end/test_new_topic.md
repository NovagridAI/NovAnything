# 新话题持久性测试指南

## 测试目的
验证点击"新话题"后创建的话题在刷新页面或重新登录后是否仍然可见。

## 测试步骤

### 📋 **步骤1：基础功能测试**
1. 登录应用
2. 点击"新话题"按钮
3. 验证：
   - [ ] 右侧话题列表出现"新话题"条目
   - [ ] 新话题被自动选中（高亮显示）
   - [ ] 聊天区域为空白状态

### 📋 **步骤2：标题更新测试**  
1. 在输入框中输入："测试消息"
2. 按Enter发送消息
3. 验证：
   - [ ] 话题标题从"新话题"更新为"测试消息"
   - [ ] 话题列表实时刷新显示新标题
   - [ ] AI回复正常

### 📋 **步骤3：页面刷新测试**
1. 刷新浏览器页面（F5或Ctrl+R）
2. 等待页面完全加载
3. 验证：
   - [ ] 话题列表中仍显示刚才创建的话题
   - [ ] 话题标题正确显示为"测试消息"
   - [ ] 可以点击话题切换回该对话
   - [ ] 聊天记录完整保存

### 📋 **步骤4：退出登录测试**
1. 退出当前账号
2. 重新登录相同账号
3. 验证：
   - [ ] 话题列表中仍显示之前创建的话题
   - [ ] 话题标题和内容都正确保存
   - [ ] 可以正常查看和继续对话

### 📋 **步骤5：空话题持久性测试**
1. 点击"新话题"创建新话题
2. **不发送任何消息**，直接刷新页面
3. 验证：
   - [ ] 话题列表中显示标题为"新话题"的条目
   - [ ] 可以点击该话题进入空白对话状态
   - [ ] 可以正常在该话题中发送消息

## 调试信息

### 浏览器控制台日志
检查以下关键日志：
```

1. 创建临时知识库...
临时知识库创建成功，ID: xxx
2. 使用模型: xxx
3. 创建新话题记录...
开始创建问答记录，参数: {...}
成功创建问答记录，返回结果: {...}
新话题记录创建成功，qa_id: xxx
4. 重置对话状态...
5. 刷新话题列表...
=== 新话题创建完成 ===
```

### 网络请求验证
在浏览器开发者工具 Network 标签中检查：
1. **POST** `/local_doc_qa/create_qa_log` - 创建话题记录
2. **POST** `/local_doc_qa/get_qa_logs` - 获取话题列表
3. **POST** `/local_doc_qa/update_qa_log` - 更新话题标题（发送消息后）

### 后端数据验证
如果有数据库访问权限，可以直接查询：
```sql
SELECT qa_id, user_id, query, result, history, timestamp 
FROM QaLogs 
WHERE user_id = 'your_user_id' 
ORDER BY timestamp DESC;
```

## 预期结果

✅ **成功的表现**：
- 新话题立即显示在话题列表中
- 页面刷新后话题依然存在
- 重新登录后话题依然存在
- 标题更新功能正常工作

❌ **失败的表现**：
- 话题只在前端显示，刷新后消失
- 网络请求失败或返回错误
- 话题标题无法更新
- 数据库中没有对应记录

## 故障排除

如果测试失败，请检查：
1. 网络连接是否正常
2. 用户权限是否足够
3. 模型配置是否正确
4. 后端服务是否正常运行
5. 数据库连接是否正常
